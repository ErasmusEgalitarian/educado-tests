\section{Execução da Suíte de Testes}

Nesta seção são apresentados os resultados obtidos pela 
equipe ao executar a suíte de testes dos repositórios
educado-web e educado-api. 



% ----------------------------------------------------------------------------
% 4.1 CONFIGURAÇÃO
% ----------------------------------------------------------------------------

\subsection{Configuração do Ambiente}

\begin{itemize}
    \item educado-web: Após a clonagem e acesso do repositório as dependências 
    do projeto foram instaladas usando \texttt{npm ci}, no entando não apresentava
    o pacote necessário para ver a cobertura, então foi preciso ser instalado por
    \texttt{npm install -D @vitest/coverage-v8}.
    \item educado-api: Após a clonagem e acesso do repositório apenas o \texttt{npm install}
    foi o suficiente para instalar todas as dependências necessárias
\end{itemize}

% ----------------------------------------------------------------------------
% 4.2 EXECUÇÃO
% ----------------------------------------------------------------------------

\subsection{Procedimento de Execução}

A execução da suíte foi realizada separadamente em cada repositório, 
conforme os comandos abaixo.

\begin{lstlisting}[language=bash]
# educado-web
cd educado-web
npm ci
npm install -D @vitest/coverage-v8
npx vitest --coverage --run

# educado-api
cd educado-api
npm install
npm run test:coverage
\end{lstlisting}

No ambiente executado, o comando do frontend retornou 
1 arquivo  de teste aprovado e o comando do backend 
retornou 31 suítes aprovadas (506 testes).

\subsection{Problemas Encontrados Durante a Execução}

O único "problema" encontrado foi a falta da dependência \texttt{@vitest/coverage-v8}
necessária para visualizar a cobertura dos testes do educado-web.

\begin{itemize}
    \item \textbf{Problemas de configuração:} foi necessário instalar o pacote \texttt{@vitest/coverage-v8} para habilitar a coleta de cobertura no educado-web;
    \item \textbf{Problemas de dependências:} ao executar \texttt{npm install} no educado-api, dos 205 pacotes foram encontradas 8 vulnerabilidades, 1 de risco baixo, 5 médio e 2 de alto risco;
    \item \textbf{Problemas relacionados ao ambiente:} nenhum;
    \item \textbf{Testes que falharam:} nenhum;
    \item \textbf{Possíveis defeitos do projeto:} baixa cobertura do educado-web indica que grande parte do código não tem validação automatizada.
\end{itemize}
