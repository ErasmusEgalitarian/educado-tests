\section{Estratégia de Testes}

Esta seção deve apresentar os aspectos relacionados a testes
identificados no projeto.

A análise deve utilizar como fontes de evidência:

\begin{itemize}
    \item documentação do projeto;
    \item código-fonte;
    \item código dos testes;
    \item arquivos de configuração;
    \item issues;
    \item pull requests;
    \item workflows de CI/CD;
    \item resultados da execução dos testes;
    \item outros artefatos relevantes.
\end{itemize}

\subsection*{Importante: evidência, avaliação e recomendação}

Ao longo desta seção, diferencie claramente:

\begin{description}

\item[Evidência encontrada:]
informação efetivamente observada no projeto. Sempre que possível,
indique a fonte da evidência, como arquivo, diretório, issue,
pull request, workflow ou trecho de código.

\item[Avaliação da equipe:]
interpretação da equipe sobre a adequação da prática identificada,
utilizando os conceitos estudados na disciplina.

\item[Recomendação:]
melhoria proposta pela equipe. Uma recomendação não deve ser
apresentada como se fosse uma prática atualmente utilizada
pelo projeto.

\end{description}
